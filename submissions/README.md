# Submissions

One folder per participant, `submissions/<github-username>/`, in lowercase. Each one arrives as a pull request and is merged at the freeze. [docs/SUBMISSION.md](../docs/SUBMISSION.md) explains how to add yours.

Never change another participant's folder. Read their code whenever you like, but run it only during the break round, inside a sandbox ([EVALUATION.md](../docs/EVALUATION.md#break-round)).
